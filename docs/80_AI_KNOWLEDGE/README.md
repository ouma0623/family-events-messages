# AI Knowledge（使い方・運用・管理）

このディレクトリは、プロジェクトをまたいで再利用できる
AI Knowledge を蓄積するための **中核（Hub）** である。

本リポジトリを新規PJへコピーして使う前提で設計されている。

---

## 何を書くか
- 判断理由・採用理由（Decision）
- ハマりどころ・失敗事例（Pitfall）
- 実装・運用の定石（Pattern）
- AIプロンプト（Prompt）
- MCP操作の定型（MCP）

## 書かないもの
- 単発の作業ログ（Issue / Notionへ）
- 仕様そのもの（requirements / design が正）

---

## 追加手順
1. 分類を決める（decision / pitfall / pattern / prompt / mcp）
2. TEMPLATES から雛形をコピーして 1ファイル作成
3. INDEX.md を更新（必須）
4. 必要に応じて Notion に要約 or リンク
